# FastGPT 官方文档索引

最后核验：2026-08-10。

FastGPT 更新较快。涉及节点行为、参数或 JSON 字段时，重新打开对应页面核验目标版本，并把目标实例实际导出的工作流作为最终结构事实来源。

## 应用类型与基础能力

- [FastGPT 官方代码仓库](https://github.com/labring/FastGPT)：核验项目发布、版本说明和开源范围。
- [FastGPT 产品概览](https://doc.fastgpt.io/guide/getting-started)：确认当前产品能力与集成定位。
- [快速开始](https://doc.fastgpt.io/guide/getting-started/quick-start)：比较对话 Agent、知识库 Agent、工作流与 Agent V2，再选择架构。

## 工作流与节点

- [文件输入功能介绍](https://doc.fastgpt.io/zh-CN/guide/build/general/fileInput)：核验文件上传开关、文件 URL 数组、文档解析与多模态处理差异，以及文件向插件/子工作流的显式传递要求。
- [工作流与插件介绍](https://doc.fastgpt.io/guide/build/workflow/intro)：核验节点输入输出、触发和 `waiting` / `active` / `skip` 执行模型。
- [AI 对话节点](https://doc.fastgpt.io/guide/build/workflow/nodes/ai_chat)：核验模型与提示词配置。
- [知识库搜索节点](https://doc.fastgpt.io/guide/build/workflow/nodes/dataset_search)：核验知识库绑定、检索输入与引用数组输出。
- [问题优化](https://doc.fastgpt.io/guide/build/workflow/nodes/coreferenceResolution)：只在多轮指代补全或查询扩展确有收益时使用。
- [内容提取](https://doc.fastgpt.io/guide/build/workflow/nodes/content_extract)：在 HTTP 调用或确定性路由前提取结构化字段。
- [HTTP 请求节点](https://doc.fastgpt.io/guide/build/workflow/nodes/http)：核验变量引用、Header、Body 序列化和 JSON Path。
- [代码运行节点](https://doc.fastgpt.io/guide/build/workflow/nodes/sandbox-v2)：核验语言和沙箱限制；不得假定代码节点可访问文件系统或内网。
- [工具调用与终止](https://doc.fastgpt.io/guide/build/workflow/nodes/tool)：控制工具数量，明确何时无需二次模型总结。
- [指定回复](https://doc.fastgpt.io/guide/build/workflow/nodes/reply)：返回固定文本或变量结果。
- [循环节点](https://doc.fastgpt.io/guide/build/workflow/nodes/loop_run)：核验版本要求、终止条件和状态回写。
- [并行执行](https://doc.fastgpt.io/guide/build/workflow/nodes/parallel_run)：仅用于相互独立的数组任务，并处理并发和部分失败。

## 知识库与 RAG

- [知识库搜索设计与参数](https://doc.fastgpt.io/guide/dataset/dataset_engine)：核验语义/全文/混合检索、RRF、重排、相似度和引用上限。
- [RAG 基础](https://doc.fastgpt.io/guide/dataset/rag)：核验切片完整性、重复、粒度和内容管理。
- [集合标签](https://doc.fastgpt.io/guide/dataset/collection_tags)：目标版本支持时用于集合过滤。
- [知识库 OpenAPI](https://doc.fastgpt.io/openapi/dataset)：核验文件类型、训练模式、切片参数和上传编码。
- [API 文件库](https://doc.fastgpt.io/guide/dataset/third-party/api_dataset)：源文档已在外部系统时，避免重复人工维护。

## 发布与集成

- [免登录窗口发布](https://doc.fastgpt.io/zh-CN/guide/build/publish/link)：核验分享链接、匿名用户标识、费用和身份验证边界；分享页是否出现上传入口取决于应用文件输入配置。
- [通过 API 访问应用](https://doc.fastgpt.io/guide/build/publish/openapi)：核验应用密钥、`appId`、额度与有效期。
- [对话接口](https://doc.fastgpt.io/zh-CN/openapi/chat)：核验消息、文件 URL、应用或分享标识以及流式返回结构；不要把网页上传能力等同于接口直接上传二进制文件。
- [OpenAPI 介绍](https://doc.fastgpt.io/openapi/intro)：核验 BaseURL、Bearer 鉴权、资源范围和版本可用性。

## 使用规则

1. 在设计或发布说明中记录实际使用的文档 URL 和核验日期。
2. 不从截图、博客或其他版本复制旧节点 JSON。
3. 区分开源版、商业版和版本限定能力。
4. 集成前重新核验 API Key 的作用域和应用绑定语义。
5. 每个发布包记录目标平台、版本和基线导出文件哈希。
6. 本 Skill 只以官方文档和目标实例行为作为 FastGPT 能力依据；同类社区项目只用于参考工程方法。
