# FastGPT 与 n8n 协同排障和文件边界

适用于异步资产/业务查询、Excel 输入、企微表格展示与平台工具授权。以下来自目标实例导出与故障证据；不是所有版本的通用 API 保证。

## 基线、模型与授权

- 最新用户导出优先于旧交付包。按 nodeId 最小修改，保留实际 URL、凭据引用、布局、Handle 和业务配置；候选来自较旧 n8n 导出时明确列出精确补丁，不能声称包含未见过的线上修改。
- 显示模型名不能当机器 ID。核对最新导出/模型列表，按用户最新偏好检查所有文本对话、分类、提取、Agent 节点；不动专用向量模型。个人供应商 ID 记录在用户/项目配置，不作为公共默认。
- Header Auth 是一个真实请求头键值对。在自定义鉴权中，键填写凭据所指定的头名，值填写对应密钥，不是建两个名为 Name 与 Value 的头。403 且无执行记录时先检查网关/Webhook鉴权，再查业务节点。
- 工具卡片与实际导出优先于过时说明。某实例「企业微信授权」工具无输入而报 null.accessToken：只证明工具后端在读取空授权对象时失败，可能与团队/账号授权记录有关；不能声称修改下游 token 变量能修复。机器人回调 Token、EncodingAESKey、企业应用 Secret 与 API access_token 是不同凭据。令牌不进入回复/日志。

## 异步任务与表存储

- Execute Workflow 引用必须是真实工作流 ID；子流程先保存发布。工作流 ID、Data Table ID/name 与凭据 ID 不可互换。简化画布不能以虚假的空表/回显分支代替真正存储。
- By Name 使用实际表名，核对同一项目下表存在且有业务列。只有系统列 id/createdAt/updatedAt 意味着自定义 schema 未建立；条件 eq 等操作符须由实际列类型/节点版本确认。
- 写入并回读任务后再派发后台处理。读取结果至少核验 found、row、data_object 和任务/机器人身份。`{op:'get',taskId,record:{}}` 是请求帧，不是持久化任务；不能包装成 found=true。
- 保留 original file/sheet/row/column 和每个输入位置。查询目标可以去重，来源账本不能丢；处理每批20项不代表业务总量上限。请求数、已处理目标数、批数分别报告。

## 响应与运行环境

- Respond to Webhook 节点右侧输出不是实际 HTTP 响应证据。若对象已在上游构造，优先验证 Response Body `={{ $json }}`；复杂展开表达式预览 undefined 时不能把业务节点成功当接口成功。Webhook 必须选择由响应节点返回。
- 分开检查 HTTP 状态、实际响应 body、FastGPT raw 变量及包装层解析。只看到请求 Headers/Body 不代表服务端有回包。错误分支应保留原因，不要统一解释为“任务不存在”。
- Code 沙箱能力按部署验证，不能假定有浏览器 URL/URLSearchParams。曾见 n8n 2.16.2 的 `URL is not defined`；离线 VM 不应额外注入该全局从而掩盖失败。库、文件/网络操作放到已验证的原生节点或明确可用运行时。
- 表达式对象展开、whole JSON/Edit Fields 行为必须实测。必要时用类型明确的手工字段与保留其他字段；不能仅凭表达式编译通过判定上游 target/config/results 未丢失。

## Excel 输入与文件输出分离

- 取消结果文件/下载，不得关闭 `fileSelectConfig`、开始节点 userFiles、Excel/CSV 解析、附件下载或后台任务。结果交付和输入解析是两条独立能力；只修改用户取消的输出链路。
- 附件校验使用管理员确认的精确来源 host；空 allowlist 的含义须明确。签名 URL 保持原路径、百分号编码及 query，不随意重编码、替换内外网域名或把允许来源扩大为任意网站。
- 全部工作表读取后按物理行关联 IP/MAC；同一行有有效 MAC 时只查询该 MAC，保留 IP 作为输入证据。无有效 MAC 时才用合规 IP；不能跨行、跨工作表拼设备。带括号说明的地址列名先规范化再判定。
- 图片提取先区分设备 IP、网关、DNS、掩码等角色，再按允许范围筛选。IP 和 MAC 属于同一设备时优先 MAC；不把掩码/越界地址显示为失败查询行。附识别信息与人工纠错提示，不把不确定 OCR 当事实。
- 文件能在服务端生成，不代表用户手机/外网能访问下载地址。FastGPT 页面、对象存储、n8n 的网络可达性分别验证。直接发送企微文件、返回智能表链接、内部下载 URL 是不同交付方式，须先验证发布通道/权限。未验证时不承诺已发送文件。

## 展示与业务状态

- 单设备默认「平台/查询结果」两列；批量「序号/目标/结果」三列。单元格内部逐字段换行，先转义字段中的管道符/HTML，再插入受控换行。行标题前后保留换行，避免批次标题粘在 Markdown 表头。只有多记录才显示匹配数量。
- 不支持当前查询类型的平台可省略，不以 unsupported 失败行占屏。无命中须以真实成功空结果或明确无命中文案为证；HTTP 错误/未知结构/部分响应不能伪装为未安装或不存在。
- 平台归一化按真实字段映射；MAC 字段可能含多个地址，以完整标准化 MAC 比对，不用单一字符串相等导致漏查。不因旧配置 types 仅含 ip 就推断服务不支持 MAC。
- 嵌套网段不是多个终端；IPAM 展示包含目标 IP 且前缀最长的一条，保留路径/描述/分区名称，省略内部 ID；原始证据保留用于复核。用户取消的冗余平台查询同步停止调用，不能仅隐藏结果。
- 来源差异需列出具体字段及各来源值，不只显示“存在2项”。防护结论依据已查询到的设备类型和成功/失败证据，不对所有设备默认下结论。设备类型与适用平台属于项目规则，不硬编码成公共资产判断。
- Ping 只由当前明确命令触发；展示接口已经返回的同网段可达设备辅助判断，但不追加扫描、不把探测服务自身 IP 当可达设备，也不凭 IP 猜实际子网掩码。

## 回归与交付证据

覆盖 Excel 同行 IP+MAC、纯 IP、跨行、重复目标、全工作表、签名链接、缺表/缺列、存储帧误当任务、空 HTTP body、未知平台结构、正常无命中、部分错误、单/多记录展示以及输出停用后上传仍有效。只有离线检查时明确写候选；不声称在平台导入、发布、授权或真实发送成功。

### 原生循环的离线可达性

目标导出可能通过 loopRun 的 childrenNodeIdList 和子节点 parentNodeId 进入 loopRunStart，没有画布入边。校验器仅在父类型为 loopRun、子类型为 loopRunStart 且双方归属一致时增加校验用虚拟入边；不修改实际工作流，也不豁免其他孤立节点。
