# FastGPT 与 n8n 协同排障和文件边界

用于异步任务、表格输入、工具授权与结果交付。适配目标节点版本，不把实例曾出现的问题当作所有版本的能力限制。

## 基线和授权

- 最新用户导出优先。按nodeId最小修改，保留无关URL、凭据引用、布局和Handle。候选源自较旧基线时明确缺口。
- 显示模型名不是机器ID。核对目标实例实际模型列表及全部文本节点，保留专用向量模型；公共技能不预设个人模型供应商。
- HTTP Header鉴权使用实际请求头键值。403且没有执行记录时先区分网关和Webhook鉴权；不要凭一段错误文案随意切换认证方式。
- 工具授权对象为空时应检查其授权来源；修改下游令牌变量不一定能修复上游授权。平台凭据、机器人回调签名和API令牌分别处理，不进入回复及日志。

## 异步任务和存储

- 工作流引用、Data Table名称/ID及凭据引用不能互换。核验目标项目表存在且有业务列，过滤操作符与列类型、节点版本一致。
- 写入并回读任务后再派发后台处理。核验读取标记、实际持久化行、内容及调用身份；请求帧不能伪装成成功读取的记录。
- 保留文件、工作表、行列和每个输入位置。查询去重不应丢来源账本；内部批大小不是业务总量上限。

## HTTP响应与运行环境

- Respond to Webhook右侧输出不证明客户端收到HTTP响应。检查实际Response Body和Webhook响应模式；上游已构造对象时可验证 `={{ $json }}`，不要用业务节点成功掩盖响应体undefined。
- 分开检查状态码、实际body、FastGPT raw变量与包装层。仅有请求信息不证明已有响应；错误分支保留原始原因。
- Code沙箱全局与库按目标部署验证，不能默认存在URL/URLSearchParams或网络权限。离线VM不要额外注入线上不可用的全局而掩盖缺陷。
- 对象展开与字段保留行为要实际验证，防止上游上下文在中间节点丢失。语法通过不等于字段正确。

## 输入解析和输出交付

- 文件上传、解析及结果下载是独立能力，只调整用户要求变更的部分。按实际导出检查fileSelectConfig、开始节点userFiles和下游引用。
- 来源校验使用管理员确认的精确host。签名URL保留原路径、编码及query；不随意重编码或替换域名。
- 多工作表关联依据原始物理行和目标项目主键规则。不得跨行、跨文件拼接对象，也不预设某种业务标识始终优先。
- 图片提取保留角色、来源和置信度，不把所有识别出的数字都当业务目标。范围筛选以项目授权为准，不确定时允许人工更正。
- 服务端生成文件不等于用户能访问。分别验证存储、链接网络可达性及发布通道的文件权限，不在未验证时承诺已经发文件。

## 展示和回归

- 按渠道实测表格列数、单元格换行、转义及消息长度；表头前后留空行。展示不能损失必要字段或污染结构化输出。
- 嵌套API响应以真实记录语义解析，一对多关系保留关联。差异展示包含字段和各来源值，不用含糊数量替代证据。
- 回归覆盖多文件、跨行、重复项、缺表缺列、存储回读错误、空响应、未知结构、成功无结果、超时、部分失败及输出关闭后输入仍有效。离线检查不代表目标平台导入或运行成功。
